Software

Open-source tools I develop and maintain for flow measurement and analysis.

LE-DM

v1.0 · Lead developer · Python

Lagrangian-to-Eulerian reconstruction with Dynamic Masking. LE-DM converts volumetric particle tracks into gridded velocity fields around moving rigid bodies of arbitrary shape, while enforcing incompressibility and the body kinematics. Because the body mask is updated throughout the reconstruction, the method explicitly accounts for moving boundaries. It is released together with its validation datasets, and a pressure extension (LE-PDM) is in preparation.

GitHub Paper Validation dataset

uPrime

v0.9.1 · Lead developer and maintainer · Python package and desktop app

An installable open-source Python package (uprime-piv) with a reusable uprime.core analysis API and a PyQt6 desktop app for PIV and CFD data. It provides turbulence statistics and budgets, probability distributions, spectra, spatial correlations, POD/DMD, vortex identification and anisotropy analysis. A software paper has been submitted to the Journal of Open Source Software.
